# Changelog

## 0.1.0 — source release candidate, 2026-09-16

Release hardening of the original MemoryCheck source snapshot. Not yet published to PyPI.

Added strict `[tool.memorycheck]` configuration, named backend loading, `doctor`, `adapter check`, `show`, `validate`, `trace`, and explicit scoped `cleanup`. Added `pytest --memorycheck` built-in collection, restart/destructive markers, verbose/private diagnostics, and distinct call-phase ERROR reporting.

Froze the normalized `QueryObservation` adapter boundary and public exception/API exports. Contracts require schema version `"0.1"`, validate reference lifetimes/scope/capabilities before mutation, and provide location-aware errors and typo suggestions. Both contract and trace JSON schemas are included as package resources.

Added generated canaries, per-run native scope namespaces, default private/redacted trace serialization, allowlisted environment metadata, caller-side deadlines, quarantine after timeout, post-observation cleanup, and private target-checked stale-run ledgers. Raw provider responses, payload metadata, and arbitrary provider exception text are not exported.

Added an updated quickstart/broken demo, configuration/adapter/privacy/reliability/API documentation, honest compatibility and validation records, source CI, a manually gated release workflow, and trace-oriented issue/security guidance. The repository has ten focused regression test functions.

### Intentional changes from the unreleased original ZIP

Adapter `query()` returns `QueryObservation` instead of a list. YAML requires `schema_version`. `RunResult.failed` no longer includes errors; use `unsuccessful` when needed. Execution errors raise `ContractExecutionError`, not `InvariantViolation`. Traces default to redaction and omit provider metadata. Native test scopes are generated by default. Successful lifecycle completion performs best-effort owned-state cleanup unless disabled. The documented Python range is 3.10–3.13.

### Validation limits

Source tests were executed; no wheel/sdist/container/application builds or package publication were run. Live Mem0 and LangGraph/PostgreSQL services were not exercised. CI configuration is supplied, not claimed to have executed. See `docs/VALIDATION.md` and `docs/RELEASING.md`.
